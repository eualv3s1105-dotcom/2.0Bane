# PROTOCOLO BANE — GitHub Pages

## Publicação
1. Extraia este ZIP.
2. Envie os arquivos e pastas diretamente para a raiz do repositório GitHub (não envie a pasta ZIP como arquivo único).
3. Faça commit na branch configurada em Settings → Pages.
4. Em Settings → Pages, selecione Deploy from a branch, a branch correta e `/(root)`.
5. Aguarde a publicação e abra a URL do Pages.

## Layout
O `index.html` mantém o conteúdo e os scripts do projeto-base, mas consolida o CSS de viewport, rolagem e navegação em uma única folha de correção. Para verificar a publicação, abra o app no Safari e recarregue a página.
